### 📢 Project Note & Intent
**First Project to work on.**
*NOTE: Every piece of information and detail mentioned in this project was used entirely with the intent of making a running prototype.*

This is a prototype of a website made with the help of emerging A.I. tools and HTML. The motive of this project was to facilitate and promote local medical shops, built with the specific intent to help local people living in a particular area or near the physical store. It serves as an interactive platform to explore the area so that consumers can easily locate and reach the store during an emergency.

---

## 🌟 Key Integrated Modules
- **Interactive First Aid Matrix:** Comprehensive step-by-step emergency triage workflows.
- **Clinical Formulation Index:** Instant local search simulation for medical conditions and brand-name drugs.
- **Active Order Manifest:** Live client-side cart billing calculations in Indian Rupees (₹).
- **Automated Operations Tracker:** Real-time business status tracking engine based on localized system clock logic.

## 🛠️ Built With
- HTML5 & Responsive Core Architecture
- Tailwind CSS (Via CDN Framework)
- Lucide Icon System Pack
- Vanilla JavaScript UI Engineering
